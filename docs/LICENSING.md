# Licensing proposal

This repository contains two kinds of material that should use different licenses:

- **Benchmark data and contextual material:** CC BY-SA 4.0. The released contexts include Wikipedia-derived material, which is made available under Creative Commons Attribution-ShareAlike terms.
- **Original code:** MIT. This is a permissive, widely used license for the code written for this project.

The authors must approve this split-license proposal before `LICENSE-DATA` and `LICENSE-CODE` files are added. Until then, no permission beyond applicable third-party terms is granted for reuse of the repository contents.
