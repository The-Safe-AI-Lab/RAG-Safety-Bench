# Camera-ready paper figures

The PNG files in this directory are rendered from the final camera-ready manuscript, **RAG-Safety-Bench: Reliable Evaluation of Retrieval-Augmented LLM Safety**. They provide convenient paper-facing visual assets for readers of the benchmark release.

The figures summarize the strict balanced evaluation set (346 questions; 1,384 condition-expanded rows per model). They are not raw model outputs or judge traces. If an image differs from the published manuscript, the camera-ready manuscript is authoritative.
